# Exercise 2: Setting up Azure Migrate for App Migration

### Estimated Duration: 15 minutes

## Overview

Azure Migrate serves as a centralized hub to assess and migrate on-premises servers, infrastructure, applications, and data to Azure. It offers a single portal to start, run, and track your migration journey. Azure Migrate includes a comprehensive range of tools that we will utilize throughout this lab, acting as the primary control center for all our assessment and migration efforts.

## Lab objectives

You will be able to complete the following tasks:

- Task 1: Setting up Azure Migrate for App Migration

## Task 1: Setting up Azure Migrate for App Migration

In this task, you will configure Azure Migrate to evaluate the readiness of your application and database for migration to Azure services.

1. In the Windows search bar, type **Default apps (1)** and select **Default apps (2)** from the results.

   ![](media/dfltapp.png)
   
1. On the **Default apps** blade, click **Internet Explorer (1)** and select **Microsoft Edge (2)** to set Microsoft Edge as your default browser.

   ![](media/dflt2.png)
   
1. Open the **Azure portal** using the desktop shortcut and log in to Azure. When prompted, use the credentials provided below to complete the login process.

    * Email/Username: <inject key="AzureAdUserEmail"></inject>
    * Password: <inject key="AzureAdUserPassword"></inject>

      ![](media/azportal.png)

1. Select your **hands-on-lab-<inject key="DeploymentID" enableCopy="false"/>** resource group. 

    ![](media/slctrg.png)

1. Select **+ Create** inside the resource group to add a new resource.
    
    ![](media/clickcreate.png)

1. Type **Azure Migrate (1)** into the search box and select **Azure Migrate (2)** from the dropdown menu.

    ![](media/azmig.png)

1. Select **Create (1)** and click **Azure Migrate (2)** to continue.

    ![](media/createazmig.png)

    >**Note:** If you are navigated to the new version of Azure Migrate, you can create a project directly from the **Get Started** page. Click **Create project** and follow the same steps.
    
1. Select **All projects** and click **(+)Create project** to create a new project.

   ![](media/allproj.png)

1. Enter **partsunlimitedweb<inject key="DeploymentID" enableCopy="false"/> (1)** as your project name. Select **Create (2)** to proceed. 

    ![](media/partsun.png)

> **Note (Updated for latest Azure Portal UI):**  
> In this lab, you may create an Azure Migrate project manually for visibility; however, the actual migration process does **not depend** on this project.  
> The lab environment already provides the required tools pre-installed on the web and database servers:
>
> - **Microsoft Data Migration Assistant (DMA)** – used for database assessment and migration.  
> - **App Service Migration Assistant** – used for web app assessment and migration.  
>
> Therefore, even if you create the Azure Migrate project, its role is limited to displaying assessment or migration data if uploaded by these tools.  
> You can safely proceed with the migration using the pre-installed tools directly.
