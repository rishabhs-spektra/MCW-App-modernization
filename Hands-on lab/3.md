# Exercise 3: Migrate your application with App Service Migration Assistant
 
### Estimated Duration: 20 minutes

## Overview

The App Service Migration Assistant is a tool designed to assess and migrate web applications to Azure App Service. You will explore how this tool identifies compatibility issues, provides remediation recommendations, and facilitates the migration of your web application to Azure’s platform-as-a-service (PaaS) environment.

## Lab objectives

You will be able to complete the following tasks:

- Task 1: Migrate the web application to Azure App Service
- Task 2: Configure the application connection to SQL Azure Database


## Task 1: Migrate the web application to Azure App Service

Having reviewed the assessment results and confirmed that the web application is a strong candidate for migration, we will now proceed with migrating the application to Azure App Service.

1. Return to the **App Service Migration Assistant** window running in the background. You can select it from the taskbar.

    ![](media/m56.png)

    > **WARNING:** If you receive this error:  
    > ![](media/loginerror.png)  
    > Repeat **Step 5** and **Step 6** from **Task 2: Perform assessment for migration to Azure App Service** of **Exercise 1: Review and Assess Legacy On-Prem Application**.

1. To proceed with the website migration, the Azure App Service Migration Assistant requires access to your Azure Subscription. Click the **Copy Code & Open Browser** button to be redirected to the Azure portal authentication page.

   ![Azure App Service Migration Assistant's Azure Login dialog is open. A device code is presented. Copy Code & Open Browser button is highlighted.](media/m51.png "Azure Login")

1. A new tab will open the login page within the Edge browser. Paste your device code **(1)** and select **Next (2)** to grant subscription access to the App Service Migration Assistant.

    ![](media/code.png)

1. Continue the login process using your Azure Subscription credentials.

   ![](media/aftercode2.png)

1. Click **Continue**.

    ![](media/m53.png)

1. Once you see the message confirming that **You have signed in to the Azure App Service Migration Assistant application on your device**, close the browser tab and minimize the Edge browser window to return to the Migration Assistant.    

    ![Azure Login process is complete. A message dialog is shown that indicates the login process is a success.](media/updated33.png "App Service Migration Assistant authentication approval")

1. In the **App Service Migration Assistant** window, select the Azure Migrate project **partsunlimitedweb<inject key="DeploymentID" enableCopy="false"/> (1)** created in the previous exercise to record the migration results. Select **Next (2)** to continue.

    ![](media/slectamp.png)

1. To migrate the Parts Unlimited website, an App Service Plan is required. The Azure App Service Migration Assistant will automatically configure all necessary requirements. Ensure the following details are configured:

    - **Subscription:** Azure HOL (SUFFIX) / Sub 05 - (SUFFIX)  **(1)**
    - **Hybrid Connection**: Select **Use existing** (1)
    - **Migration Results**: Select the resource group **hands-on-lab-<inject key="DeploymentID" enableCopy="false"/>** **(2)**
    - **Destination Site Name**: Enter **partsunlimited-web-<inject key="DeploymentID" enableCopy="false"/>** **(3)**.
    - **Region**: Select **<inject key="location" style="color:red" />** **(4)**. 
    - Click **Migrate** **(5)** to start the migration process.

      ![](media/clickmig.png)

      > **WARNING:** If your migration fails with a **WindowsWorkersNotAllowedInLinuxResourceGroup (1)** error, it may be due to an incorrect region. Try the migration process again and ensure you select the correct region.  
      
      > ![Migration failed error screen is shown. WindowsWorkersNotAllowedInLinuxResourceGroup message is highlighted.](media/updated35.png "Migration failed")

      > You will see a confirmation message once the migration completes successfully.     

        ![](media/migdone.png)

## Task 2: Configure the application connection to SQL Azure Database

In this task, you will configure your application to successfully connect to the newly provisioned SQL Azure Database.

Now that both the application and database have been successfully migrated to Azure, you must configure the web application to securely connect to the SQL Azure Database.

1. In the Azure portal, navigate to your `parts` SQL Database resource by opening the **hands-on-lab-<inject key="DeploymentID" enableCopy="false"/>** resource group and selecting the `parts` SQL Database from the list of resources.

   ![](media/sqldbslect.png)

1. Switch to the **Connection strings (1)** blade, and copy the connection string located under **ADO.NET (SQL authentication)** by clicking the copy button **(2)**.

   ![](media/cnctstrings.png)

1. Paste the connection string into a text editor, such as Notepad, to replace the password placeholder. Replace the `{your_password}` section with **<inject key="SQLVM Password" />**. Copy the complete, updated connection string for later use.

    ![Notepad is open. SQL Connection string is pasted in. {your_password} placeholder is highlighted.](media/sql-connection-string-password-replace.png "Database connection string")

1. Return to the resource list, search for `partsunlimited-web` **(1)** to locate your Web App and App Service Plan. Select your **partsunlimited-web-<inject key="DeploymentID" enableCopy="false"/> (2)** App Service resource.

   ![](media/srchweb.png)

1. Switch to the **Environment variables (1)** blade, select **Connection strings (2)**, and click **+ Add (3)**.

    ![](media/envt.png)

1. On the **Add/Edit connection string** panel, enter the following:

   - **Name (1)**: Enter `DefaultConnectionString` **(1)**
   - **Value (2)**: Paste the SQL Connection String you prepared in Step 3. **(2)**
   - **Type (3)**: Select **SQLAzure (3)**
   - **Deployment slot setting (4)**: Check this option to ensure the connection string is securely pinned to this specific deployment slot. This will be critical when configuring additional deployment slots in upcoming exercises.
   - Select **Apply (5)**.

     ![](media/addstring.png)

1. Select **Apply (1)** and **Confirm (2)** in the subsequent Save changes dialog.

   ![](media/m61.png)

1. Switch to the **Overview (1)** blade and click the **Default domain (2)** link to view the newly migrated Parts Unlimited website hosted on Azure App Service, now seamlessly integrated with your Azure SQL Database.

    ![](media/dd.png)
    
1. A new browser tab will open, displaying the fully functional application running on Azure App Service.

    ![](media/azweb.png)
